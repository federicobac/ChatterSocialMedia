# ChatterSocialMedia

A social media application built with React, TypeScript, Vite and Bun.

## Features

- View a feed of posts
- Search for posts
- Open a single post
- View comments
- Delete posts
- Create posts

## Technologies

- React
- TypeScript
- React Router
- Vite
- Bun
- DummyJSON
